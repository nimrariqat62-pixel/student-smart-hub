OOP • FOUR PILLARS

1. ENCAPSULATION

Keeping data and related functions together inside a class and controlling access to data.

2. ABSTRACTION

Showing important features and hiding unnecessary implementation details.

3. INHERITANCE

A new class can reuse and extend features of an existing class.

4. POLYMORPHISM

The same interface can have different behaviours, such as with function overloading.


SIMPLE OOP PROGRAM EXAMPLE

#include <iostream>
using namespace std;

class Student {
public:
    void greet() {
        cout << "Keep learning!";
    }
};

int main() {
    Student learner;
    learner.greet();
    return 0;
}

* Student is a class; learner is an object; greet() is a member function.
