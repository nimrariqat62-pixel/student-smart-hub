Q1: What is a Flowchart?

A flowchart is a graphical representation of an algorithm or process[span_1](start_span)[span_1](end_span). It uses different symbols connected by arrows to show the sequence of steps required to solve a problem or complete a task[span_2](start_span)[span_2](end_span).

Purpose of a Flowchart:

A flowchart helps us understand a process easily by presenting its steps in a clear, systematic visual form[span_3](start_span)[span_3](end_span).

Flowchart Symbols

1. Terminator (Start / End)

Shape: Oval[span_4](start_span)[span_4](end_span)

Work: It indicates the beginning and the end of a program or process[span_5](start_span)[span_5](end_span).

Example: START and END[span_6](start_span)[span_6](end_span)

2. Process

Shape: Rectangle[span_7](start_span)[span_7](end_span)

Work: It represents calculations, data processing, or an instruction in a program[span_8](start_span)[span_8](end_span).

Example: Sum = A + B[span_9](start_span)[span_9](end_span)

3. Input / Output Symbol

Shape: Parallelogram[span_10](start_span)[span_10](end_span)

Work: Used for inputting data or displaying output results[span_11](start_span)[span_11](end_span).

Example: Input A, Print Sum[span_12](start_span)[span_12](end_span)

4. Decision Symbol

Shape: Diamond (Rhombohedron)[span_13](start_span)[span_13](end_span)

Work: Checks a condition and directs flow based on result (Yes/No or True/False)[span_14](start_span)[span_14](end_span).

Example: If (A > B)[span_15](start_span)[span_15](end_span)

5. Flowline Symbol

Shape: Arrow[span_16](start_span)[span_16](end_span)

Work: Shows the direction of the process flow[span_17](start_span)[span_17](end_span).

6. Predefined Process Symbol

Shape: Rectangle with vertical lines[span_18](start_span)[span_18](end_span)

Work: Represents a subroutine or module defined elsewhere[span_19](start_span)[span_19](end_span).

7. Document Symbol

Shape: Rectangle with wavy bottom line[span_20](start_span)[span_20](end_span)

Work: Represents a printed report or document generated[span_21](start_span)[span_21](end_span).

Examples of Flowchart

Example 1: Addition of Two Numbers

1. START 2. Input Two Numbers A and B 3. Calculate Sum = A + B 4. Display Sum 5. END

Example 2: Check Even or Odd

1. START
2. Input number N
3. Check if N % 2 == 0
   - YES: Display "EVEN"
   - NO: Display "ODD"
4. END
