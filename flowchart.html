What is a Flowchart

A Flowchart is a graphical representation of an algorithm or process. It uses different symbols connected by arrows to show the sequence of steps required to solve a problem.

Purpose of a Flowchart

A Flowchart helps us understand a process easily by presenting its steps in a clear, systematic visual form.

Flowchart Symbols Section

1. Terminator (Start / End)

Shape: Oval

Work: It indicates the beginning and the end of a process.

Example: START and END

2. Process

Shape: Rectangle

Work: It represents calculations, data processing and operations.

Example: Sum = A + B

3. Input / Output

Shape: Parallelogram

Work: Used for inputting data or displaying output results.

Example: Input A, Print Sum

4. Decision

Shape: Diamond

Work: Checks a condition and directs flow based on result (Yes/No or True/False).

Example: If (A > B)

5. Flowline

Shape: Arrow

Work: Shows the direction of the process flow.

6. Predefined Process

Shape: Rectangle with vertical lines

Work: Represents a subroutine or predefined elsewhere.

7. Document

Shape: Rectangle with wavy bottom line

Work: Represents a printed report or document generated.
