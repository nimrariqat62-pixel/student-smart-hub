# 🎓 Student Smart Hub

Welcome to **Student Smart Hub** — a dedicated academic management portal and study guide designed for BSCS students.

## 📌 Features

- **BSCS 1st Semester Academic Portal:** Comprehensive study guides for Programming Fundamentals (C++), Applications of ICT, and Discrete Structures.
- **C++ Code Snippets & Notes:** Structured reference materials covering syntax, control loops, arrays, pointers, and algorithm techniques.
- **Responsive "Royal Purple" Design:** Fully optimized for mobile and desktop screens using clean HTML5 & CSS3.
- **Korean Language Corner (Coming Soon):** Hangul basics, daily conversational phrases, and TOPIK exam study prep.
