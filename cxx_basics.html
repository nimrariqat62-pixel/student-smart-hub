01. C++ Basic Structure & Input/Output

Detailed Explanation: C++ is a case-sensitive programming language where all keywords must be written in lowercase. Every C++ program execution begins from the main() function. The cout object combined with the insertion operator (<<) is used to display output on the screen, while the cin object combined with the extraction operator (>>) is used to take user input from the keyboard. 

#include <iostream>
using namespace std;

int main() {
    int number;
    cout << "enter a number: ";
    cin >> number;
    cout << "you entered: " << number << endl;
    return 0;
}
🔍 Program Breakdown / Post-Mortem:
• #include <iostream>: Preprocessor directive that includes standard input/output stream library functions into the program.
• using namespace std;: Allows direct use of standard library components (such as cout, cin, and endl) without prefixing them with std::.
• int main(): The mandatory main entry point function where program execution officially starts.
• cin >> number;: Reads integer input from the user via keyboard and stores it inside the number variable.

02. Variables & Data Types

Detailed Explanation: Variables are symbolic names given to memory locations used to store data during program execution. Data types instruct the compiler about the kind of value a variable will hold, such as whole numbers, floating-point numbers, characters, or boolean flags. Primary data types include int, double, char, and bool. 

#include <iostream>
using namespace std;

int main() {
    int age = 19;
    double gpa = 3.9;
    char grade = 'a';
    bool ispassed = true;

    cout << "age: " << age << endl;
    cout << "gpa: " << gpa << endl;
    return 0;
}
🔍 Program Breakdown / Post-Mortem:
• int age = 19;: Allocates memory space to store an integer value 19.
• double gpa = 3.9;: Declares a double-precision floating-point variable to store decimal numbers accurately.
• char grade = 'a';: Stores a single character enclosed within single quotation marks.

03. Operators (Arithmetic, Relational, Logical)

Detailed Explanation: Operators are special symbols that perform mathematical, relational, or logical operations on variables and values. Arithmetic operators (+, -, *, /) handle calculations, relational operators (>, <, ==) compare values, and logical operators (&&, ||) combine multiple conditional expressions. 

#include <iostream>
using namespace std;

int main() {
    int a = 10, b = 5;
    int sum = a + b; 
    bool check = (a > b); 
    bool logicaltest = (a > 5 && b < 10); 

    cout << "sum: " << sum << endl;
    cout << "check: " << check << endl;
    return 0;
}
🔍 Program Breakdown / Post-Mortem:
• a + b: Arithmetic addition operator that computes the sum of variables a and b.
• (a > b): Relational expression evaluating whether a is greater than b, returning a boolean result.
• &&: Logical AND operator that evaluates to true only when both operand conditions are simultaneously true.

04. Control Structures (If-Else & Switch)

Detailed Explanation: Control structures dictate the execution path of a program based on specific runtime conditions. if-else statements evaluate boolean expressions to direct execution into alternative branches of code. 

#include <iostream>
using namespace std;

int main() {
    int marks = 85;

    if (marks >= 80) {
        cout << "grade: a" << endl;
    } else {
        cout << "grade: b" << endl;
    }
    return 0;
}
🔍 Program Breakdown / Post-Mortem:
• if (marks >= 80): Evaluates whether the variable marks is greater than or equal to 80.
• else: Fallback execution block that runs if the preceding condition evaluates to false.

05. Iteration / Loops (For, While, Do-While)

Detailed Explanation: Loops are control structures used to execute a block of code repeatedly as long as a specified condition remains true. A for loop is typically utilized when the exact number of iterations is known in advance. 

#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 3; i++) {
        cout << "iteration count: " << i << endl;
    }
    return 0;
}
🔍 Program Breakdown / Post-Mortem:
• int i = 1;: Initializes the loop control counter variable.
• i <= 3;: The conditional test checked before every iteration; loop continues while true.
• i++: Increment expression executed at the end of each iteration to update the counter.

06. Arrays & Strings

Detailed Explanation: An array is a data structure that stores a fixed-size sequential collection of elements of the same data type in contiguous memory locations. Individual elements are accessed using zero-based index numbers. 

#include <iostream>
using namespace std;

int main() {
    int scores[3] = {90, 85, 88};
    cout << "first score: " << scores[0] << endl;
    return 0;
}
🔍 Program Breakdown / Post-Mortem:
• int scores[3]: Declares an integer array capable of holding 3 elements.
• scores[0]: Accesses the first element stored at index position 0 within the array.

07. Functions & Scope

Detailed Explanation: A function is a self-contained block of code designed to perform a specific, reusable task, improving modularity and code readability. A void return type indicates that the function does not return any value back to the caller. 

#include <iostream>
using namespace std;

void greetstudent() {
    cout << "welcome to student smart hub!" << endl;
}

int main() {
    greetstudent();
    return 0;
}
🔍 Program Breakdown / Post-Mortem:
• void greetstudent(): Defines a user-defined function named greetstudent with no return value.
• greetstudent();: Invokes (calls) the function from inside the main() function to execute its code block.
