01. C++ Basic Structure & Input/Output

C++ aik case-sensitive language hai. Is mein sab keywords lowercase (chote huroof) mein hote hain. `cout` screen par data display karne ke liye aur `cin` user se input lene ke liye istemal hota hai. 

#include <iostream>
using namespace std;

int main() {
    int number;
    cout << "enter a number: ";
    cin >> number;
    cout << "you entered: " << number << endl;
    return 0;
}
🔍 Line-by-Line Breakdown:
• #include <iostream>: Header file jo input/output capabilities provide karti hai.
• using namespace std;: Standard C++ library features ko direct use karne ke liye.
• int main(): Program ka main entry point.
• cin >>: Keyboard se user input lene ke liye extraction operator.

02. Variables & Data Types

Variables memory location ke naam hote hain jahan data store hota hai. Primary data types: int, double, char, aur bool. 

#include <iostream>
using namespace std;

int main() {
    int age = 19;
    double gpa = 3.9;
    char grade = 'a';
    bool ispassed = true;

    cout << "age: " << age << endl;
    cout << "gpa: " << gpa << endl;
    return 0;
}
🔍 Line-by-Line Breakdown:
• int age = 19;: Memory mein integer variable create kiya.
• double gpa = 3.9;: Decimal values store karne ke liye high precision type.

03. Operators (Arithmetic, Relational, Logical)

Operators symbols hote hain jo variables aur values par operations perform karte hain (jaise addition, comparison, aur logical conditions check karna). 

#include <iostream>
using namespace std;

int main() {
    int a = 10, b = 5;
    int sum = a + b; // arithmetic
    bool check = (a > b); // relational
    bool logicaltest = (a > 5 && b < 10); // logical

    cout << "sum: " << sum << endl;
    cout << "check: " << check << endl;
    return 0;
}
🔍 Line-by-Line Breakdown:
• a + b: Arithmetic operator jo values ko add karta hai.
• a > b: Relational operator jo true ya false return karta hai.
• &&: Logical AND operator, jo dono conditions true hone par true deta hai.

04. Control Structures (If-Else & Switch)

Control structures program ke flow ko decide karte hain ke kaun sa block run hoga aur kab conditions ke mutabiq decision liya jayega. 

#include <iostream>
using namespace std;

int main() {
    int marks = 85;

    if (marks >= 80) {
        cout << "grade: a" << endl;
    } else {
        cout << "grade: b" << endl;
    }
    return 0;
}
🔍 Line-by-Line Breakdown:
• if (marks >= 80): Condition check karta hai ke marks 80 se zyada hain ya barabar.
• else: Agar condition false ho toh yeh block execute hota hai.

05. Iteration / Loops (For, While, Do-While)

Loops aik hi code ko bar bar execute karne ke liye istemal hote hain jab tak koi specific condition true rehti hai. 

#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 3; i++) {
        cout << "iteration count: " << i << endl;
    }
    return 0;
}
🔍 Line-by-Line Breakdown:
• int i = 1;: Loop counter initialize kiya.
• i <= 3;: Condition jab tak true rahegi loop chalega.
• i++: Har iteration ke baad counter mein 1 ka izafa karta hai.

06. Arrays & Strings

Array aik hi data type ki multiple values ko ek sath continuous memory location par store karne ke liye use hota hai. 

#include <iostream>
using namespace std;

int main() {
    int scores[3] = {90, 85, 88};
    cout << "first score: " << scores[0] << endl;
    return 0;
}
🔍 Line-by-Line Breakdown:
• int scores[3]: 3 integers ki capacity wala array banaya.
• scores[0]: Array ka pehla element access karne ke liye index 0 ka istemal.

07. Functions & Scope

Function code ka aik reusable block hota hai jo specific task perform karta hai, jisse code clean aur manageable rehta hai. 

#include <iostream>
using namespace std;

void greetstudent() {
    cout << "welcome to student smart hub!" << endl;
}

int main() {
    greetstudent();
    return 0;
}
🔍 Line-by-Line Breakdown:
• void greetstudent(): Aik user-defined function jo koi value return nahi karta.
• greetstudent();: Main function ke andar function ko call kiya gaya hai.
